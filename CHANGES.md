- Settings > DCS Modes: when *Choose DCS Launcher* or *Choose Normal or VR mode* is off, three exclusive buttons decide what the launcher does at each launch (they are shown shaded while the choice is on): **Default** (the launcher does not touch `options.lua`, as before: nothing changes for anybody after updating), **With launcher / Without launcher** (`miscellaneous.launcher`) and **Normal / VR** (`VR.enable`). With *With launcher* the mode is not applied (the DCS launcher asks for it itself), exactly as when it is chosen. *Enable VR mode by instance* now works with the VR mode fixed too (DCS starts from the second Saved Games folder and the DCS optimizations are installed there as well), not only with the Normal / VR choice. New settings `skip_launcher_fixed` and `dcs_mode_fixed`.
