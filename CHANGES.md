- Release 2.1.0. Everything since Release 2.0.0 is in `RELEASE_TEXT.md`: themes (Orange, Blue, Light and Automatic), rounded buttons, the redesigned Free VRAM list (a Reopen box per program, Remove all, the simulation button), a lighter background polling, the fix of the message window when DCS ends with nothing else to close, and the removal of the code that only served very old versions.
- About / Credits: a new section "Support the project" says that NOVA Launcher is free and made without any profit motive and links to https://buymeacoffee.com/Pier_Paolo (also in the READMEs), with room above the CLOSE button.
- The installer carries the release number in its name also on the `main` branch of the download site (`NOVA_Launcher_Setup_2.1.0.exe` and its `.sha256`), as it already did on the Release page; `main` holds only the installer of the latest release. The `builds` branch keeps the plain name.
